
Installation
============

Using pip
---------

The easiest way to install PTO-transits is using pip:

.. code-block:: bash

    pip install PTO-transits

Requirements
------------

PTO requires Python 3.10 or later and the following packages:

* numpy
* matplotlib
* pandas
* seaborn
* astropy
* sympy
* pyvo
* specutils
* colorlog
* dill
